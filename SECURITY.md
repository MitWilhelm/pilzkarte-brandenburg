# Sicherheit

Die Pilzkarte ist ein privates Projekt. Eine Sicherheitslücke bitte **nicht** in einem öffentlichen Issue melden, sondern
über „Security“ → „Report a vulnerability“ im GitHub-Repository (privater Meldeweg). Gemeldet werden können z. B. Wege,
Meldungen zu fälschen oder zu überschwemmen, Schlüssel offenzulegen oder fremden Code in die Seite zu bringen.

Wie die Seite geschützt ist und welche Risiken bleiben: `docs/sicherheit.md`.
